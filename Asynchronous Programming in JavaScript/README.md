# Asynchronous Programming Exercises

The examples use only Node.js core functionality.

- `iterateWithAsyncAwait(values)` logs each value with a one-second pause between values.
- `awaitCall()` waits for a simulated API response, logs the data, and reports failures with a friendly message.
- `chainedAsyncFunctions()` awaits three one-second async steps in sequence.

Run all examples with `npm start` and tests with `npm test`.
